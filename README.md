| Concepto / Instrucción           |         Python            |            JavaScript                 |                 C#                    |
|               :---               |          :---             |               :---                    |                :---                   |
| **1. Condicional (If-Else)**     | `if x > 0: ... else: ...` | `if (x > 0) { ... } else { ... }`     | `if (x > 0) { ... } else { ... }`     |
| **2. Bucle controlado (For)**    | `for i in range(5): ...`  | `for (let i = 0; i < 5; i++) { ... }` | `for (int i = 0; i < 5; i++) { ... }` |
| **3. Bucle condicional (While)** | `while x < 5: ...`        | `while (x < 5) { ... }`               | `while (x < 5) { ... }`               |
| **4. Definir una función**       | `def saludar(): ...`      | `function saludar() { ... }`          | `void Saludar() { ... }`              |
| **5. Crear una lista / arreglo** | `numeros = [1, 2, 3]`     | `const numeros = [1, 2, 3];`          | `int[] numeros = {1, 2, 3};`          |
| **6. Valor Booleano**            | `activo = True`           | `let activo = true;`                  | `bool activo = true;`                 |
